# بناء HydraMind AI سحابياً

هذا إعداد بناء للمصدر الكامل، وليس بديلاً عن ملفات Flutter. يلزم وجود `pubspec.yaml` و`lib` و`android` و`assets` في جذر المستودع. لا يمكن إعادة بناء التطبيق من ملف APK فقط.

## تشغيل البناء

1. ارفع المصدر الكامل إلى جذر المستودع، بعد فك أرشيف المصدر إن كان يحتوي مجلداً خارجياً باسم `hydramind`.
2. افتح المستودع في GitHub ثم **Actions → Build HydraMind Android APK**.
3. اضغط **Run workflow** وحدد الفرع `main`.
4. إذا أردت رابط APK عاماً داخل Releases، فعّل **Publish the APK as a downloadable GitHub Release**.
5. شغّل المهمة وانتظر نجاح الاختبارات والبناء. لا يُنشأ إصدار إذا فشل البناء.
6. للتنزيل: افتح نتيجة المهمة ثم **Artifacts → HydraMind-AI-Android-arm64**. الملف المحمّل ZIP؛ فكّه للوصول إلى APK. أو افتح **Releases → Assets** إذا فعّلت النشر.

البناء التلقائي على `main` يرفع Artifact وينشر إصدار APK بعد نجاح الاختبارات والبناء. عند التشغيل اليدوي يمكنك إلغاء خيار النشر لإنتاج Artifact فقط. لا حاجة إلى لصق Token بالمحادثة أو إضافته إلى المشروع؛ مهمة النشر تستخدم `GITHUB_TOKEN` المؤقت الخاص بـ Actions بصلاحية `contents: write`.

## التوقيع

دون أسرار توقيع، ينتج APK تجريبي بمفتاح التطوير الخاص بالمشغّل. المفتاح قد يتغير بين عمليات البناء؛ تحديث نسخة مثبتة بمفتاح مختلف قد يتطلب إزالة النسخة السابقة، وهذا قد يمسح بياناتها. احتفظ بمفتاح ثابت للإصدارات الموزعة.

للتوقيع الثابت، أضف هذه القيم في **Repository Settings → Secrets and variables → Actions → New repository secret**:

- `ANDROID_KEYSTORE_BASE64`: ملف keystore بترميز Base64، دون أسطر فاصلة.
- `ANDROID_STORE_PASSWORD`.
- `ANDROID_KEY_PASSWORD`.
- `ANDROID_KEY_ALIAS`.

هذه الأسرار اختيارية ويجب تقديمها معاً إن استُخدمت. لا ترفع keystore أو `key.properties` أو `.env` إلى GitHub. يحذف المسار الملفات المؤقتة بعد التنفيذ.

## حالة المصدر

أُعيد إنشاء المصدر في 2026-11-18 من الأكواد والسلوك الموثقين بالمحادثة، لأن أرشيف الجلسة السابقة لم يعد متاحاً. هذه نسخة مستعادة، وليست استرجاعاً مطابقاً لأرشيف المصدر القديم أو APK القديم. الإصدار الجديد `1.0.1+2`. نتائج GitHub Actions على commit الحالي هي المرجع لنجاح البناء، والاختبارات المحلية لا تثبت توصيل الإشعارات أو التكاملات الصحية على جهاز حقيقي.
